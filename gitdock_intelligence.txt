=== GITDOCK SENTINEL (AI SECURITY WORKER) ===
Description : Microservice Python/FastAPI agissant comme chien de garde. Audite les commits en temps réel via LLM, mémorise le code dans ChromaDB et notifie via RabbitMQ/WebSockets.

=== PROCÉDURE DE RESET COMPLET (NETTOYAGE AVANT DÉMO) ===
1. Tuer les processus fantômes (Ports occupés) : 
   sudo pkill -9 python
2. Purger la file Kafka (Lag) : 
   Aller sur Kafka UI (http://100.89.63.25:8090) -> Topic "cleaned-commits" -> Clear Messages
3. Purger la base vectorielle ChromaDB : 
   Ouvrir http://100.89.63.25:8010/docs -> Exécuter DELETE /api/sentinel/flush-chroma
4. Stopper les scripts parasites : 
   S'assurer qu'aucun chaos_producer.py ne tourne en arrière-plan.
